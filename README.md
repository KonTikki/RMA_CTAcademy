Luka Kirasić, Dorian Kljajić, Giovani Goglia, Luka Žagar, Matej Tomac

Aplikacija služi kao edukacijska platforma o pravilnom održavanju i samostalnom popravku računala. Također služi za pronalazak specifičnog problema u hardveru računala. Nudi grafički prikaz hardvera, prikaz kompatibilnosti komponenti, step-by-step vodič do rješenja problema. Korisnici također imaju opciju traženja videozapisa na temelju postojećeg problema.
